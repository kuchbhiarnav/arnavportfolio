# Arnav Patnaik's Portfolio

Astro 7 + TypeScript portfolio, fully static, deployed on Vercel from GitHub. The original Arnav Patnaik's Portfolio look, rebuilt on accessible foundations, with evidence-linked case studies.

```bash
npm install
npm run dev        # http://localhost:4321
npm run verify     # type-check + build + tests
```

Environment: only `SITE_URL` (the public address, for canonical links, social previews and the sitemap). See `.env.example`. There are no API keys and no server routes.

Start with `docs/`:

1. Content audit and decisions needed · 2. Positioning and copy · 3. Architecture · 4. Case-study checklist · 5. Setup and environment · 6. Cost table · 8. Verification results · 9. Maintenance

**Note on the docs:** the chatbot (assistant), the Gemini AI service and the Cloudflare setup were removed on 14 November 2026. Any section of `docs/` that describes them is historical.
