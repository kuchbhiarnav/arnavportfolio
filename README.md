# Arnav's Archive

Astro 7 + React 19 + TypeScript portfolio, deployed as a Cloudflare Worker. The original Arnav's Archive look, rebuilt on accessible foundations, with evidence-linked case studies and a grounded assistant.

```bash
npm install
npm run dev        # http://localhost:4321
npm run verify     # type-check + build + 140 tests
```

Start with `docs/`:

1. Content audit and decisions needed · 2. Positioning and copy · 3. Architecture · 4. Case-study checklist · 5. Setup and environment · 6. Cost table · 7. Assistant knowledge and prompt · 8. Verification results · 9. Maintenance

Nothing has been deployed and no paid service has been activated. AI answers are **off by default**.
